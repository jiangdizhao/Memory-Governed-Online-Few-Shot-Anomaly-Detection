# Self-matching and source provenance

Support self-scoring can be optimistically biased because the fixed bank was built from augmentations of the same Supports. Its initialization is a cold-start heuristic; a Support-group-excluded diagnostic can be implemented in a later separately reviewed workflow and is not used to select theta here.

L stores the pre-feedback score and never reinterprets that scalar as a current-memory score. Its score can be stale as Greedy or C1 changes. E stores the complete `(784, 4096)` fused tensor, original geometry, dtype, normalization convention, event/group hashes, state identities and genuine query receipt for each verified normal. The cache preserves float32, the dtype returned by the frozen native encoder. It rejects FP16 input: synthetic CPU C1 exposed a native half-precision matrix multiplication failure, and no FP16 conversion parity has been established. Each FP32 tensor uses 12,845,056 bytes; 1,024 such tensors require up to 13,153,337,344 bytes before Python and other state overhead. The cache reports actual tensor allocation and refuses overflow.

`GreedyProvenance.write_normal` makes a disposable same-device mirror, reproduces full-feature native normalization, the native candidate order and `v02_memory.greedy_slot`, invokes the unchanged real writer, then compares the complete prototype tensors and occupancy exactly. Each active slot retains its source-group union, admitted feature identity, patch and position history. On replacement the overwritten slot's prior sources remain in the union. An unexplained mismatch invalidates the sidecar; neither a tensor digest alone nor an unknown source is accepted as provenance.

E clones the scoring bank and filters every dynamic slot whose union contains the calibration group, leaving the fixed Support bank untouched. The original tensors and both provenance/digest states are checked before and after. If all dynamic slots are excluded, the native scorer uses the fixed reference. It then recomputes the full dense normal map and Top-32 patch indices and applies R1's native C1 source filter to those newly selected features. The filter excludes every C1 slot whose conservative group union contains the source, including older contributors to a replaced slot.

This removes direct same-source Greedy prototype and C1 anchor matches from the current score. It does not undo earlier admission decisions, capacity pressure, replacement paths or other adaptive effects. It is not counterfactual retraining.

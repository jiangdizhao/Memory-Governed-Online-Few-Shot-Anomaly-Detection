# FS4 selection-aware threshold implementation contract

Status: implementation and CPU synthetic verification only. No scientific execution is authorized by this contract. The immutable native reference is built from exactly four registered Supports and their native approved augmentations. No additional predeployment normal image is encoded or used for calibration, novelty, correction, query cost, or writer admission.

`build_native_from_four_support` accepts exactly four distinct Support paths and source hashes, an augmentation mapping containing exactly those paths, the four identity feature tensors and four CLS vectors. It calls the unchanged P0 native builder and configures empty native Greedy and C1 banks at K=1024. Future data orchestration must independently bind those caller-supplied identities and feature tensors to the registered dataset manifest before calling this interface.

For the four native Support self-scores, `support_self_reference` uses the historical P0 convention: sample standard deviation (`ddof=1`), a 1e-6 initializer floor, and `theta0 = mean + 2.5 * max(sample_std, 1e-6)`. Both G and GC and both controllers begin at that same threshold; C1 starts empty. This is an uncalibrated self-score heuristic with only four observations. The independent writer reference is frozen before feedback at this theta and `sigma_ref = max(sample_std, 0.02)`; native writer eligibility chooses its existing 8/16/24 rule with novelty zero. Low or degenerate Support variation is reported rather than tuned on a stream.

For each legally queried verified normal, the statistical engine uses the recorded two-stage probability `pi = 0.2 * gate_probability`, raw weight `1/pi`, and operational weight `min(1/pi, 50)`. It requires at least 12 distinct source groups and clipped-weight ESS `(sum w)^2 / sum(w^2) >= 12`. The q90 is the first sorted score whose inclusive weighted empirical CDF reaches 0.90; ties return the shared tied value. With equal weights this is nearest rank `ceil(0.9*n)`, which is not generally NumPy `higher`'s `ceil(0.9*(n-1))` index. For each genuinely new evidence or relevant scorer-state token, the engine clips the q90 to the previous threshold +/-0.01. Separate G and GC thresholds take effect only for later events.

L retains only bounded scalar pre-feedback G/GC scores and metadata, and labels them historical as memory changes. E retains full native fused feature tensors from verified queried normals only, at most one per group and 1,024 groups; it refuses overflow. It recomputes G and GC under current memory with direct same-source Greedy and C1 exclusion. Both use exactly the same `WeightedThresholds` implementation. Missing selection probabilities, provenance, sufficient groups, ESS, or current-state scoring hold the threshold with an explicit status.

The public shared interface computes the prior query scale, scores G/GC once, seals predictions and feature/Top-32 identities, decides and seals the query, legally discloses only executed-query feedback, performs C1 then eligible Greedy updates, and only then makes future threshold updates. Shared mode uses a separate frozen Support-derived query reference and common frozen writer reference. Coupled mode gives each independently owned system its own policy and controller-dependent query reference; the writer remains frozen. Any future coupling of thresholds to writer admission is a different intervention requiring its own authorization.

### 3.1 Minimal verified-evidence interface (specification, not an implementation claim)

For each **actually queried** image, store or reconstruct from immutable legitimate historical receipts:

`{event_id, class_id, official_group_id, query_decision_time, reveal_time, verified_label, memory_version_at_prediction, source_prototype_ids, score_at_arrival, feature_ref_digest, query_policy_id, propensity_if_known, calibration_eligible}`

- A stored field is **optional unless available and verified**; absent `source_prototype_ids` or features needed for current-state/leave-source-out scoring => `BLOCKED_INPUT_STATE`, **not** an invented backfill.
- `verified_label` is unavailable prior to the query's actual reveal; no unqueried label is written to the deployment ledger.
- Positive (defect) anchors **never** enter normal Greedy memory; verified normal anchors may enter Greedy only through the frozen, existing writer.
- When a labeled normal has contributed patches to current dynamic memory, any *separate queried-anchor* current-state calibration uses documented **leave-source-out** (exclude its own source prototypes); protected-C64 B3 uses C64 only and must **not** be mislabeled as an LSO variant.
- Similarity/defect-anchor evidence is **not** automatically an unbiased estimate of stream FNR. Deterministic BEA has zero-propensity regions; IPW is not justified without legal, positive-probability sampling and sufficient data.
- First implementation may be read-only views of existing sources rather than a new persistent bank. Do not mutate legacy correction anchors or add gradient training.
